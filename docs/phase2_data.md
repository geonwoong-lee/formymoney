# Phase 2 공식 상품 데이터

Phase 2는 Supabase 대신 프로젝트 내부 SQLite3를 사용한다. 사용자 답변과 계산 결과는 저장하지 않고, 공개된 상품 규칙과 은행별 조건만 저장한다.

## 첫 지원 범위

- 공통 상품: 청년미래적금, 36개월, 월 1천원~50만원, 연 600만원 한도
- 정부기여금: 일반형 6%, 우대형 12%
- 세금: 만기 수령을 전제로 비과세
- 은행: KB국민은행, 신한은행

공식 문서에서 기본금리, 최고금리, 개별 우대조건과 기준일을 모두 확인할 수 있는 두 은행부터 지원한다. 나머지 은행은 공식 조건을 검수한 뒤 추가한다.

## 처리 원칙

- 금액과 금리는 오차를 줄이기 위해 정수와 소수 전용 형식으로 저장한다.
- 조건마다 사용자 질문, 쉬운 설명, 가산금리와 공식 출처를 분리한다.
- 기간·과거 거래·복합 요건처럼 답변만으로 확정하기 어려운 조건은 `추가 확인 필요`로 표시한다.
- 초기 데이터 입력은 여러 번 실행해도 같은 행이 중복되지 않는다.
