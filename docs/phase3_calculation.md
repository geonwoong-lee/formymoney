# Phase 3 적금 계산 기준

## API

- `GET /api/v1/savings/products`: 공통 상품 규칙, 지원 은행, 질문과 출처를 제공한다.
- `POST /api/v1/savings/calculate`: 월 납입액, 정부기여금 유형, 은행별 조건 답변으로 예상 결과를 계산한다.

사용자 답변은 `yes`, `no`, `unknown` 중 하나다. `unknown`과 별도 증빙이 필요한 조건은 금리에 더하지 않고 `needs_review`로 돌려준다.

## 첫 계산 방식

Phase 3은 매달 같은 금액을 36개월 납입하는 경우를 계산한다. 월별 감액·미납은 Phase 5에서 다룬다.

- 원금: 월 납입액 × 36개월
- 예금 이자: 각 납입금이 남은 개월만큼 이자를 받는다고 보고 단리로 합산
- 정부기여금: 일반형 6%, 우대형 12%, 미대상 0%
- 정부기여금 이자: 은행 기본금리와 실제 납입 기간을 적용
- 만기 예상액: 원금 + 예금 이자 + 정부기여금 + 기여금 이자
- 세금: 정상 만기 비과세를 전제로 0원
- 원 단위 반올림: 일반적인 사사오입

예상금리는 은행 기본금리에 자동 확인 가능한 우대금리만 더하며, 공시 최고금리를 넘지 않는다. 결과는 예상 만기액이 큰 순서로 정렬하지만 특정 은행을 추천한다고 표현하지 않는다.

## 주의

이 결과는 고정 납입을 가정한 예상값이다. 실제 가입 자격, 납입일, 중도해지, 은행의 최신 공시와 조건 판정에 따라 달라질 수 있다.
